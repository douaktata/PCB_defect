LE MODÈLE

Six défauts. Une seule analyse.

YOLO11n localise les anomalies dans les images de cartes électroniques. L’inférence utilise une résolution de 1280 pixels pour préserver les défauts de petite taille. Les boîtes sont restituées dans les coordonnées de l’image d’origine, après correction de son orientation EXIF.

PÉRIMÈTRE DE VALIDATION

Des résultats à contextualiser.

  • Les défauts du dataset sont artificiels : ils ne couvrent pas toute la variabilité de la production réelle.
  • Le jeu de test porte sur deux cartes seulement. La généralisation à de nouvelles cartes reste à évaluer.
  • Le cuivre parasite présente une précision de 0,61 ; l’excroissance, un rappel de 0,79.
  • « Aucun défaut détecté » ne garantit pas une carte sans défaut. Le score de confiance n’est pas une probabilité calibrée.
